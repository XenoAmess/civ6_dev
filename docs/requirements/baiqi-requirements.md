# 白绮【为我前驱】需求与验收边界

版本：2026-10-31，P4 强制托管修订。最新用户指令优先于历史可选托管与独立经营设计。本文定义要交付的行为；[玩法设计](../design/baiqi-delegate-execution.md)说明方案，[有偿夺取设计](../design/baiqi-requisition.md)记录技术与规则草案。执行方法见[验收方案](../testing/baiqi-acceptance-plan.md)，具体步骤见[测试用例](../testing/baiqi-test-cases.md)。

需求与测试设计已形成基线，现有[开发原型及首轮实测](../implementation/baiqi-prototype.md)，尚未通过完整验收。任何源码入口、模型候选或文档检查通过，都不能记为游戏验收通过。

## 目标与来源

制作新领袖【白绮】，领袖能力【为我前驱】：自动生产、自动建造、自动和平扩张，玩家集中指挥战斗；军队还可以在一定条件下付出代价夺取他人的城市；粮仓经营方案已由用户删除，其他建筑夺取尚未交付。

以下表格用三种来源区分约束，避免将实现选择写成用户原话：

- **用户**：用户明确提出的名称、玩法目标与控制权边界，完整交付必须满足。
- **推导**：为了让这些目标可靠工作而制定的工程要求，如正常扣费、权限拦截、读档恢复；实现时按此验证。
- **设计目标**：当前采用的量化体验目标，必须测量，尚无达成证据。具体预算按验收配置冻结。

“自动”指默认无需逐城选择生产、逐次给建造者下令或为移民逐格规划。玩家仍结束回合、指挥军队和决定对外关系；内政不能交回玩家。科技、市政、政策自动选择已进入实现范围，其他内政尚未闭合者必须报告缺口。自动招募军队属于生产；移动、攻击等军事命令属于玩家。

## 必须冻结、目前未定的规则

| 项目 | 当前方向／尚缺内容 |
| --- | --- |
| 运行范围 | 首个目标是单人《风云变幻》；文明归属、所需 DLC 与已测版本需冻结。多人、热座及 AI 使用本领袖尚未承诺。 |

## 交付边界

本文定义可追踪的需求和验收边界。按生产／建设、文职扩张、军队隔离、有偿夺取分阶段实现与验收时，必须逐项标明通过范围；部分链路通过只能交付相应原型；强制托管、正常建设扩张和军队指挥尚有缺口时不能宣布完整达标。

自动外交、自动军队指挥、头像美术和通用战斗加成不纳入本轮功能验收。内政自动化的未实现部分必须逐项标明，不得以手动接管作为验收替代。开发阶段使用本地模型，不代表玩家运行模组也要调用模型。
