# 白绮【为我前驱】需求与验收边界

版本：2026-10-31。本文定义要交付的行为；[玩法设计](../design/baiqi-delegate-execution.md)说明方案，[有偿夺取设计](../design/baiqi-requisition.md)记录技术与规则草案。执行方法见[验收方案](../testing/baiqi-acceptance-plan.md)，具体步骤见[测试用例](../testing/baiqi-test-cases.md)。

当前仅完成需求与测试设计，游戏功能尚未实现、用例尚未执行。任何源码入口、模型候选或文档检查通过，都不能记为游戏验收通过。

## 目标与来源

制作新领袖【白绮】，领袖能力【为我前驱】：自动生产、自动建造、自动和平扩张，玩家集中指挥战斗；军队还可以在一定条件下付出代价夺取他人的城市、建筑等。

以下表格用三种来源区分约束，避免将实现选择写成用户原话：

- **用户**：用户明确提出的名称、玩法目标与控制权边界，完整交付必须满足。
- **推导**：为了让这些目标可靠工作而制定的工程要求，如正常扣费、手动优先、读档恢复；实现时按此验证。
- **设计目标**：当前采用的量化体验目标，必须测量，尚无达成证据。具体预算按验收配置冻结。

“自动”指默认无需逐城选择生产、逐次给建造者下令或为移民逐格规划。玩家仍结束回合、指挥军队，并处理本轮未纳入自动化的科技、市政、政策和外交。自动招募军队属于生产；移动、攻击等军事命令属于玩家。

## 必须冻结、目前未定的规则

下列项由后续设计与原型证据确定，再写入[验收配置](../testing/baiqi-acceptance-plan.md#验收配置)。这不是要求本次补实现或立即选定数值；受影响的实测在配置缺失时记为 `BLOCKED`。不能将核心需求删掉来换取通过。

| 项目 | 当前方向／尚缺内容 |
| --- | --- |
| 运行范围 | 首个目标是单人《风云变幻》；文明归属、所需 DLC 与已测版本需冻结。多人、热座及 AI 使用本领袖尚未承诺。 |
| 经济策略 | 招募需求上限、财政储备、战略资源余量、扩张名额、最低人口、地块保护与规划频率；应按游戏状态计算，不写死为任意一局的常数。 |
| 夺取资格 | 战时、邻接可行动地面军队、外城防御破坏、城市生命低于阈值是首个试验方向；单位类别、距离、阈值、首都／城邦等特殊对象资格均未定。 |
| 夺取代价 | 金币加本次军队行动消耗是草案；币种、费用函数、报价有效条件、回合次数与冷却未定。未来若换币种，保留边界与只结算一次的验收。 |
| 转移后规则 | 主要文明城市与特殊城市的占领、忠诚度、建筑转换、人口及驻军处理需记录；不能仅从赠送城邦效果推断。 |
| 独立资产 | 至少分别研究建筑与其他设施的真实控制；城市所属建筑如何合法关联、区域与改良如何控制尚无实现结论。受引擎限制时报告目标未完成和具体证据。 |
| 性能与体验 | 五城二十回合是已有设计目标；十城每轮规划时限、请求上限、允许额外耗时和稳定性采样长度需在跑测前冻结。 |

## 交付边界

本轮交付是可追踪的需求和验收方案。后续可按生产／建设、文职扩张、军队隔离、有偿夺取分阶段实现与验收，但必须逐项标明通过范围；城市夺取通过而独立建筑未通过时，只能交付城市部分，不能宣称本领袖完整达到要求。

科技、市政、政策、自动外交、自动军队指挥、头像美术和通用战斗加成不纳入本轮功能验收。商路、买地等可以另列扩展，不得用它们取代上述核心流程。开发阶段使用本地模型，不代表玩家运行模组也要调用模型。
