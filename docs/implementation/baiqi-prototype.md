# 白绮原型：安装、操作与验证范围

更新：2026-10-31，配置 `BAIQI_P2`。可安装原型包含自动内政与玩家确认的城市／粮仓经营权征取；尚未达到[完整需求](../requirements/baiqi-requirements.md)的全部验收条件。当前实机证据见 [P2 报告](../testing/results/2026-10-31-p2-requisition.md)，早期失败与修正保留在 [P1 报告](../testing/results/2026-10-31-p1-smoke.md)。

## 安装与运行

在仓库根目录通过 CMD 执行：

```bat
python -m pip install -r requirements-dev.txt
python -m unittest discover -s tests -v
python tools\build_mod.py --install
```

测试使用 `lupa` 执行实际 Lua 5.3 源码；打包工具只依赖 Python 标准库。玩家运行模组不需要 Python、本地模型或网络服务。生成 `dist/Baiqi.zip`，安装到当前用户文档目录的 `My Games/Sid Meier's Civilization VI/Mods/Baiqi`；可用 `--mods-dir` 指定其他位置。安装器拒绝覆盖非工具管理的同名目录或用户编辑过的已安装文件，不递归删除目录。

在游戏“额外内容”启用【白绮：为我前驱】，新建单人对局选择白绮。原型关联中国文明，引用已安装的中国标志与加载画面，不含第三方美术，也不继承秦始皇领袖能力。前端提供标准／迭起兴衰／风云变幻入口，**实机仅验证风云变幻**。多人、热座及其他界面模组组合未纳入支持。

## 操作

内政默认开启，无需逐城设置。面板可开关总托管、接管／交回所选城市或文职、保护所选对象所在地块。手动队列优先；军队由玩家指挥。科技、市政、政策、外交及结束回合仍由玩家决定。设置保存在游戏属性中。

征取由玩家选择自己的军队，再点面板按钮；显示目标与费用后确认。多座邻城时按坐标确定本次报价目标，确认框会显示名称和位置。取消不发请求；后台不会主动发动征取或宣战。总内政开关不禁用手动征取。

| 动作 | 共同条件之外的条件 | 费用与效果 |
| --- | --- | --- |
| 征取相邻城市 | 外部防御已清零，城内生命 ≤35% | `200 + 100 × 人口` 金币，整城原位转归白绮并接入内政；正常转移可能改变城市标识和资产状态 |
| 征取粮仓经营权 | 外部防御已清零，存在完好的原版粮仓；白绮有接收城市 | 150 金币，粮仓留在敌城，原城扣除 1 粮食／2 住房，白绮接收城市得到对应经营功能 |

共同条件：单人白绮人类玩家当前回合；当前可见的敌城；与目标交战；所选近战／抗骑兵／轻重骑兵陆军相邻、有行动力、无护送编队，且本回合未发动过征取。成功结束该单位本回合行动，其他军队不受影响。

经营权首版仅支持未被其他模组改变基础效果或追加 modifier 的普通粮仓，最多 16 处；默认接收城市是白绮城市标识最小的城市，并在确认框具名。使用原生食物与住房 modifier，无建筑复制、无金币冒充产出。原建筑受损时暂停，修好恢复；源城或接收城易手、源建筑被移除时结束。白绮取得源城后结束经营权，转用整城正常经营效果，避免双算。不是所有建筑、奇观或独立区域／改良都已支持。

未知或中断操作保留记录并冻结冲突目标／单位，不自动重试、退款或根据当前归属推断成功。正常拒绝由面板显示；本地测试可用只读 [inspect_baiqi.lua](../../tools/inspect_baiqi.lua) 在引擎调试上下文读取实际资产和结算记录。脚本不属于玩家运行依赖。

## 实现与边界

| 文件 | 职责 |
| --- | --- |
| [模组清单](../../mod/Baiqi/Baiqi.modinfo)、`Config/`、`Data/`、`Text/` | 领袖注册、本地化、文明关联、原版图标引用；不覆盖原版文件 |
| [BaiqiPolicy.lua](../../mod/Baiqi/Lua/BaiqiPolicy.lua)、[BaiqiPlanner.lua](../../mod/Baiqi/Lua/BaiqiPlanner.lua) | 文职与动作白名单、编队和权限门槛、合法候选、预算、城址与结算状态转换 |
| [BaiqiController.lua](../../mod/Baiqi/Lua/BaiqiController.lua) | 空生产队列、区域坐标、建造者与移民规划；写入前重检、随后读取实际结果 |
| [BaiqiRequisition.lua](../../mod/Baiqi/Lua/BaiqiRequisition.lua)、[BaiqiCapture.lua](../../mod/Baiqi/Lua/BaiqiCapture.lua) | 共享资格报价、游戏侧重检、实际城市转移、经营权取得与单次费用／行动结算 |
| [BaiqiRights.lua](../../mod/Baiqi/Lua/BaiqiRights.lua)、[BaiqiRights.sql](../../mod/Baiqi/Data/BaiqiRights.sql) | 保存原位经营权，门控原生双向产出与住房效果，生命周期刷新；不重复附着 modifier |
| [BaiqiGameplay.lua](../../mod/Baiqi/Lua/BaiqiGameplay.lua)、[BaiqiActions.lua](../../mod/Baiqi/Lua/BaiqiActions.lua)、`UI/` | 原版脚本事件路由、持久化设置、显式确认、只读结果展示与视图生命周期 |

[BaiqiConfig.lua](../../mod/Baiqi/Lua/BaiqiConfig.lua) 固定本轮原型参数：0.35 秒检查、每回合最多 64 请求、每城最多 512 候选；财政储备 100、预测净收入至少 2；移民最低人口 4，全帝国最多一个已有／在建／预留移民承诺；建造者目标每两城一个，军队每城两个且至少两个。均无最终平衡或性能达标结论。

文职每次只请求一格已探明安全路径，不带攻击修饰，不进入外方领土、不移动护送编队；不能保证避开未知敌军。区域保护现有设施、地貌、可见资源和玩家保留地块；建城遵循原版合法条件。生产结合 `CanProduce(hash,true)` 与 `CanProduce(hash,false,true)`：实机证明只用后一项会错误接受未研究科技的粮仓。

城市转移使用实机已核实的原生 `CityManager.TransferCity`，不是销毁重建；但不是完整战时征服语义验收。原位、人口和粮仓已观察保留，其他资产、驻军、外交、占领和忠诚度仍需分别验证，不能承诺全部无损。
