## 安装与操作

在仓库根目录通过CMD执行：

```bat
python tools\build_mod.py --install
```

在“额外内容”启用模组并选择领袖【白绮】。当前实测目标是《风云变幻》单人；其他规则集、多人、热座及其他UI模组组合尚未验收。领袖关联中国，不继承秦始皇领袖能力；新头像及版本29头部安全区已实际显示；版本30分离选人／加载构图后在1024×728窗口实机通过头部和双手显示，静态外交及其他缩放仍待完成，来源与导出见[美术记录](baiqi-art-sources.md)。安装器校验自己的旧清单与文件指纹，发现用户修改会拒绝覆盖。替换UI脚本或美术后须冷启动。游戏运行不依赖本地模型服务；普通开发和验收保持Steam离线。

选择白绮即强制托管内政、生产、建设和和平移民扩张。玩家查看内政、指挥军队并结束回合；没有右侧模组面板、托管开关、暂停、接管或地块保留入口，旧暂停标记无效。已存在的合法队列与进度继续保留。后台只对明确支持的文职下令，不移动或解散护送编队；将军与海军统帅由玩家指挥。

移民、建造者、闲置商人商路、科学家／工程师／商人伟人、普通建筑匹配槽位的创作，以及先知前往安全圣地并建教选信条已有受支持范围。版本31允许无区域前置的三类文职伟人在当前自有、可见、安全格经原生资格确认后激活；不猜测其他条件的目的地。派发前重检身份、编队、行动与地块，未知结果跨回合保留pending，不因闲置／次数未变就重发。232项软件测试通过；正常招募阿布·卡西姆已实机自动激活并产生铸造术尤里卡，其他新增个体待验，未知请求跨存读档持久化仍未实现。人工对应命令受保护；其他条件伟人、特殊建筑及其他宗教单位仍未闭合，不能让玩家接管来替代实现。

军队仍用原版方式操作。符合条件的陆军直接与敌城作地图交互，再选择征取、正常进攻或取消。当前原型要求：本地白绮人类单人当前回合，可见交战敌城；近战、抗骑兵或轻重骑兵陆军相邻、有行动、无护送编队且本回合未征取；敌城外防为零、生命不高于35%。费用为`200 + 100 × 人口`金币，成功后结束该军队本回合行动，数值尚未平衡。

征城恢复依据实际持久化回执：已确认转移而尚未开始扣费的阶段可补齐结算；已确认扣费的阶段直接结算军队行动，不重复扣费。结果不明的原生调用仍冻结冲突操作，不凭余额或归属猜测、不退款，也不扣新回合行动。

粮仓经营权和“解放地块”已删除；旧效果清理且旧请求拒绝，不补发收益。用户2026-11-01明确取消全部独立建筑夺取，只保留征城；建筑随整城按原生规则转移，不设置独立经营权、收益抽取或使用权。整城资产变化仍须核对。
