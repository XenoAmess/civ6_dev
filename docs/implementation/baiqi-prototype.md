## 安装

通过 CMD 执行 `python tools\build_mod.py --install`，在“额外内容”启用【白绮：为我前驱】，选择白绮创建单人对局。模组关联中国，使用已安装的原版图标与加载图，不继承秦始皇能力。实测目标为《风云变幻》；其他规则集、多人、热座和其他 UI 模组组合未验收。

安装器验证清单、路径和旧安装指纹。仅删除旧清单中属于本工具、内容未被修改且新清单已撤销的具体文件；保留其他文件，不递归删除目录。遇到用户修改则拒绝覆盖。移除 UI 脚本／清单后需冷启动内容，不能只热加载旧存档内的脚本。

## 操作

选择白绮即强制托管。玩家可以查看城市、研究与政策，不能更改生产／购买／市民／地块和移民、建造者、商人和科学家命令，也不能暂停或取回控制。旧版关闭／暂停标记不再生效；旧已有生产队列继续正常完成。没有右侧模组面板。

军队继续用原版方式操作。选中符合条件的陆军，直接右键敌方城市；达到征取条件时，出现该城市与代价的确认，可选择“征取城市”“继续正常进攻”或“取消”。普通进攻沿用该次目标坐标，不跟随弹窗打开后移动的光标。后台不会征城、宣战、议和或指挥军队。

当前征城参数：单人白绮人类玩家当前回合、可见交战敌城；近战／抗骑兵／轻重骑兵陆军相邻、有行动、没有护送编队，本回合未征取；外防为零、城市生命不高于 35%。费用 `200 + 100 × 人口` 金币，成功后结束该军队本回合行动。未核实结果冻结冲突操作，不自动重放或退款。这些是原型数值，尚未平衡。

粮仓经营权已删除，当前版本也不提供其他独立建筑操作；其他建筑夺取仍属未完成目标。迁移清除旧粮仓出入效果和经营权表，不退款或补发收益；旧记录保留历史意义，不能重新请求。“解放地块”也已删除：旧功能仅清除玩家地块保留标记，让自动建设重新考虑该格，从来没有解放领土、改变所有权或拆除敌方设施。

旧存档可能保留已挂接的效果实例，因此保留一份[零收益兼容定义](../../mod/Baiqi/Data/BaiqiRetiredEffects.sql)，不增加任何建筑／区域挂接；旧属性写为 0。直接删除所有定义曾在实机触发异常收益，不能以“属性已清除”代替实际产出检查。

## 实现

| 模块 | 作用 |
| --- | --- |
| [Controller](../../mod/Baiqi/Lua/BaiqiController.lua)、[Policy](../../mod/Baiqi/Lua/BaiqiPolicy.lua)、[Planner](../../mod/Baiqi/Lua/BaiqiPlanner.lua) | 合法空队列、建筑／区域生产、文职与安全城址规划；正常成本、有界请求，军队不进入后台动作白名单 |
| [Admin](../../mod/Baiqi/Lua/BaiqiAdmin.lua) | 空科技／市政路径自动选择、免费政策窗口填空槽、正常头衔任命／派驻／晋升总督；保留已生效队列／政策／派驻，不猜原生函数 ABI |
| [UIGuard](../../mod/Baiqi/Lua/BaiqiUIGuard.lua)、[UILoader](../../mod/Baiqi/Lua/BaiqiUILoader.lua)、`UI/Baiqi*.lua` | 在原版 UI 上限制人工写入，保留军队、其他领袖和只读信息；按规则集包含最上层原版脚本，不复制游戏资产或重复初始化 |
| [Actions](../../mod/Baiqi/Lua/BaiqiActions.lua)、[Requisition](../../mod/Baiqi/Lua/BaiqiRequisition.lua)、[Capture](../../mod/Baiqi/Lua/BaiqiCapture.lua) | 地图交互报价、提交前与游戏侧重检、原生城市转移、费用／行动防重日志 |
| [Gameplay](../../mod/Baiqi/Lua/BaiqiGameplay.lua)、[Executor](../../mod/Baiqi/UI/BaiqiExecutor.lua) | 游戏侧迁移／路由与不可交互的后台执行器。执行器不导入人工 UI 拦截器 |

规划参数见 [Config](../../mod/Baiqi/Lua/BaiqiConfig.lua)：0.35 秒、每回合最多 64 请求、每城最多 512 候选、财政储备 100、预测净收入最低 2、移民最低人口 4、已有／在建／预留移民合计最多一个。军队总量仍为每城 2（至少 2），侦察单位计入总量且新增上限为 `max(1,ceil(城市数/4))`；已有斥候不删除。可训练项中优先平衡近战与远程，原生合法性、资源和维护费照常检查，军事分数低于学院。保护现有设施、地貌和可见资源是系统策略，没有玩家保留地块开关。
