# 为我前驱：城市征取

玩家选中自己的军队后，直接右键与目标敌城交互。合格时展示城市名称与费用，提供征取、继续正常进攻、取消三个选择；不使用右侧模组按钮。没有合格报价时保留原版移动／攻击流程。后台内政不能发动此动作。

当前开发配置为 `BAIQI_P4`：交战、当前可见、相邻可行动陆军（近战／抗骑兵／轻重骑兵）、无护送编队；外防已破、城市生命 ≤35%；`200 + 100 × 人口` 金币并结束本单位本回合行动。数值是实现选择，尚未平衡。确认前重读目标、单位、费用与人口；改变后需重新交互，不能转用当前鼠标位置或静默改变价格。

游戏侧再次验证并生成关联日志，再用原生城市转移；核实归属后扣费并结束行动。成功只结算一次；取消和明确未执行不扣费。中间阶段未知则冻结，不盲重发、退款或仅凭当前归属推断成功。实际占领、驻军、忠诚度与资产转换须单独验收，不能把原位转移当完整战时征服证明。

用户已删除粮仓经营权；其他独立建筑操作尚未实现，不能以此取消原始建筑夺取目标。旧原位经营实验仅保留在 [P2 历史报告](../testing/results/2026-10-31-p2-requisition.md)；新版本移除脚本、SQL、文本与入口，清理旧存档的经营效果，不退款、不重放。当前建筑随城市转移按原生规则处理。

资格、支付、重复、取消、未知、迁移与资产测试见[需求表](../requirements/baiqi-requirements.md)、[用例 TC-023～TC-034](../testing/baiqi-test-cases.md)和[当前报告](../testing/results/2026-10-31-p4-mandatory.md)。
