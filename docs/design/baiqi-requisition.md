# 白绮有偿夺取设计

【为我前驱】在自动生产、自动建造与和平扩张之外，新增由玩家指挥军队使用的有偿夺取能力：满足场景条件、支付代价后，夺取他人的城市、建筑等。该效果由玩家决定目标和时机，后台内政只在资产取得后接管经营。

领袖和能力名称、付费夺取目标、玩家军队指挥权是已确定需求。下述“征取”动作名、战时条件和费用结构均为首个原型的建议，尚未确定最终数值或完成游戏内实现。

对应[需求 BR-016～BR-024](../requirements/baiqi-requirements.md)；[验收方案](../testing/baiqi-acceptance-plan.md)规定参数冻结、取证和判定，[TC-023～TC-034](../testing/baiqi-test-cases.md#tc-023)给出具体步骤。城市转移与独立建筑／设施转移分别验收，不能相互替代。

## 首个玩法草案

建议在所选军队的操作栏加入一个按条件出现的【征取】动作，提示目标、未满足的条件与完整代价。玩家选择目标并确认后执行一次；取消或条件不成立不产生费用。

城市的初始测试条件建议为：与目标所属方处于战争状态；白绮一支可行动、具备占城资格的地面军队与目标相邻；目标外部防御已被打破，城市生命降至预设阈值。这样可以先通过作战形成接管机会，再用经济和行动成本提前结束争夺。

主要代价建议使用现有金币，同时结束发动单位本回合的行动。费用按时代、人口与城市价值调整，每单位每回合的次数受限，避免一支军队连续免费接收多城。费用公式、生命阈值、冷却及适用兵种均待测试；不新增专门货币。

首都、城邦、含奇观城市、特殊防御和独特建筑应分别测试其规则，不将“先用普通城市验证”写成永久排除这些目标。和平状态下付费接管或其他触发方式仍可研究，首个草案不自动替玩家宣战。

## 城市与建筑的夺取范围

| 目标 | 需要实现的效果 | 当前设计与边界 |
| --- | --- | --- |
| 城市 | 城市实际转归白绮，再进入自动经营 | 优先验证整城归属转移；必须核对城市位置、人口、领土、区域、建筑和持续状态 |
| 随城市取得的建筑 | 对本次转移规则保留的建筑和设施继续经营 | 逐项核对真实保留、损毁和变换情况，不能默认所有建筑、独特建筑和巨作无损保留 |
| 独立建筑或区域 | 不依赖整城取得的设施夺取 | 保留为明确需求，单独验证所属城市、地块、区域、建筑和产出的关联；当前未找到可直接据以承诺的通用转移操作 |
| 农场、矿山等地块设施 | 设施及其所在领土或收益控制发生实际变化 | 需要明确资产归属与结算方式，不能把一次性掠夺奖励当成已实现的设施夺取 |

原版 UI 通过 `OwnerCity:GetBuildings()` 管理建筑信息。只把对方一座图书馆“改成归白绮”，仍需解决它关联的城市、区域和收益；不能在未核实机制时承诺可把建筑直接搬到另一座城市。

第一段可玩验证可以从“取得整座城市，同时核实其中可保留的建筑”开始。独立设施夺取的验证结果另外记录，不因整城转移成功就记为全部目标完成。

## 玩家决定与支付一致性

自动建设、扩张和军队招募均不能主动发动征取。执行入口只接受玩家本次指定的单位、目标与已展示的代价，重新检查领袖、所有权、战争状态、距离、单位行动和目标状态。

同一目标与单位只能有一个待处理请求。费用结算、单位行动消耗与目标归属必须通过同一笔操作记录关联；请求发出后读回实际结果，不能把按钮响应或已发出请求当作夺取成功。

支付与转移的具体先后顺序需结合实测后的游戏侧处理方式确定，不能假设普通 UI 请求天然提供事务。验收需要满足：

- 明确失败时不损失费用和单位行动；若实际路径要求预扣，失败补偿只能针对原操作执行一次。
- 成功时只结算一次费用和行动成本，不能把同一笔请求重复执行或扣费。
- 结果未知时暂停该操作，保留证据并核对归属与对应结果，不盲目重试或退款。
- 读档后先恢复操作记录，再核对目标及结果；不能仅凭目标目前已归白绮就推断一定是本次能力成功。
- 结算前财力不足、目标易手或发动单位失去资格时按明确规则终止，不能把失败惩罚临时改为破产。

成功取得的城市接入自动修复和建设，但忠诚度、占领、外交后果及驻军处置必须核实具体转移路径的结果。不能借用“赠送城市”的效果就默认它等同战时征服。

## 最小试验

1. 核对原版城邦吸收效果的实际前置与结果，作为参考路径；再单独测试敌方主要文明城市，不能把前者成功外推为后者成功。
2. 在本地可控对局记录目标的原归属、地块位置、城市标识、人口、区域、建筑、驻军、巨作、忠诚度和生产队列；执行后建立旧新对象映射并逐项比较。
3. 分别验证条件满足、不足金币、失去行动力、距离不符、目标易手和单位失去的情况，确保失败不产生不应有的支出。
4. 对一次确认、多次点击、延迟结果、保存读档和重复回执核对费用及行动次数，测试未知结果不会重复夺取。
5. 核实战时外交、占领、忠诚度和驻军语义；成功城市自动接入经营，其他军队不受影响。
6. 独立建筑、区域与地块设施分别做关联及收益测试，验证实际资产控制变化，不能用重建一份建筑或发放掠夺金币替代需求。

只有归属转移、代价结算和玩家主动控制同时跑通，才能把有偿夺取记为可玩功能。
