# 白绮与为我前驱设计规格

最新用户约束：领袖【白绮】，能力【为我前驱】。选择后强制由 AI 处理内政、生产、建造与和平扩张，玩家只读查看并指挥军队。不能暂停、夺回控制或逐城设置。旧可选托管方案已撤销。

| 范围 | AI 负责 | 玩家负责 |
| --- | --- | --- |
| 内政 | 建筑、区域选址、改良、修复、科技、市政、政策及后续内政决策 | 查看信息，不能修改 |
| 扩张 | 正常训练移民、已探明安全城址和路径、到达重检、正常建城、新城接入 | 侦察与战争决策 |
| 军队 | 按需求和预算训练后交付玩家 | 移动、攻击、升级、编队等全部军事指挥 |
| 有偿征城 | 只执行玩家指定、确认并满足资格的那次动作 | 选军队，直接对敌城交互并选择支付、正常进攻或取消 |
| 对外关系 | 不自动宣战／议和 | 对外决策与结束回合 |

全部建设按正常成本和真实完成计数。空队列补充、资源／财政／人口预算、所有者重检、未知结果冻结和正常读档恢复见[需求](../requirements/baiqi-requirements.md)。已探明不代表当前可见，安全检查不能读取迷雾敌军；无安全路线就等待。文职编队移动会带动军队，必须跳过，不能自动解散编队。

没有右侧管理／征取面板；原版城市／研究／政策只读，军事 UI 保留。文职没有手动接管入口。旧“解放地块”仅是解除人工保留标记，命名误导，已与保留开关一起删除。粮仓经营权也完全删除；用户2026-11-01已取消独立建筑夺取，只保留整城征取及建筑随城转移。

实现与设计目标分开：当前支持与缺口见[原型说明](../implementation/baiqi-prototype.md)，征城详见[专项设计](baiqi-requisition.md)，实际通过范围见[测试报告](../testing/results/2026-10-31-p4-mandatory.md)。[早期源码预研](custom-leader-autobuild-research-2026-10-31.md)和[扩张证据](../research/baiqi-expansion-evidence-2026-10-31.json)只证明相应研究时点，旧人工接管描述不覆盖新要求。
