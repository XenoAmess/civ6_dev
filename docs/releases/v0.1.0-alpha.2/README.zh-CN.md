# 白绮【为我前驱】Alpha 2

选择白绮，研究、政策、生产、建设和文职扩张强制托管；军队与外交由玩家决定。可查看内政，不能接管或暂停。先读[已知问题](KNOWN_ISSUES.zh-CN.md)和[更新说明](RELEASE_NOTES.md)。

[GitHub Alpha2预发布包](https://github.com/XenoAmess/civ6_dev/releases/tag/v0.1.0-alpha.2)已公开，内部82／93文件；公开附件下载后的93文件逐项与pin一致。实际工坊最后核验仍为Alpha1构建74，Steam尚未同步。计划更新[同一工坊条目](https://steamcommunity.com/sharedfiles/filedetails/?id=3833805495)，不另建条目。

可直接下载Release附件及SHA256SUMS.txt核对。开发者在仓库根目录执行`python tools/build_mod.py --output dist/Baiqi-v0.1.0-alpha.2.zip`可生成安装包。解压后将Baiqi目录置于文明VI用户Mods目录，在额外内容启用，使用单人《风云变幻》选择白绮。已有工坊或手动副本时只保留一个启用的相同Mod ID，避免重复加载。正常游玩不需要模型服务。
