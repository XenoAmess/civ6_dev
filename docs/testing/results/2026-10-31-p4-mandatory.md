## 行为变更

选择白绮后强制托管，没有右侧模组面板、总开关、逐城／文职接管或地块保留入口。原版城市、研究与政策界面限制人工写入；军队继续走原版操作。空科技／市政自动选路径，免费政策窗口填空槽；其他内政对象的完整自动决策仍未闭合。

征城接入 `WorldInput` 和 `UnitPanel` 的原版 `MoveUnitToPlot` 入口，合格敌城弹出确认、普通进攻、取消；不使用独立征城按钮。费用与游戏侧结果需要重检并唯一结算。

粮仓经营权删除。其他建筑夺取的原始目标尚未交付，不能以本轮迁移成功代替。“解放地块”原来只是解除玩家保留标记，让自动建设重新考虑那一格；没有领土解放、归属转移、占领或拆除效果。该命名与保留入口均移除。

## 失败与修正保留

1. UI 沙箱没有 `rawset`，首次代理载入报错。改为普通表赋值，并在替身中移除 rawset；之后新上下文加载、只读与原版方法调用通过。
2. 删除全部经营效果 SQL、把属性设 nil 后，旧存档双方出现额外 `+15` 粮食／`+30` 住房。原因与旧存档持有的效果实例、缺失需求定义相关，但未把推测说成引擎内部已证实。保留 34 个旧 ID 的零收益兼容定义，不增加建筑／区域挂接，并将旧属性置 0；冷启动读回双方正常值。
3. 新地图消费者最初没有导入 `BaiqiPolicy`，普通军队移动报错。补齐 Requisition 和两个地图上下文的依赖，测试改为执行真实 include 链；重载上下文后军队移动、报价与真实确认成功。
4. `SKIP_TURN` 可能保持行动点不变；单靠行动点变化读回会使待处理槽跨回合滞留。现在其等待意图在换回合时退出，软件覆盖次回合重新评估。引擎只观察到一次等待请求，不宣称完整等待行为通过。
5. Tuner 只接受单连接，异步日志可能先于 LSQ；并行诊断连接被重置、旧脚本曾把日志误当上下文。改用顺序连接、按实际消息类型解析和当前上下文名称绑定；查询失败时没有重放游戏动作。

前期正常生产观察另有 T10 纪念碑、T16 建造者真实完成，属于旧控制方案下的历史片段；不作为新版强制托管的完整 TC-006／TC-011 通过。早前未核对 CanSlotPolicy 双参数诊断造成测试进程崩溃，已经停止该签名试探；新实现使用核对过的原版政策请求格式。
