# 114 实机：商路断粮发生在人口下降之前

用 211 的独立健康档再走两个普通回合，邢州再次从 8 人掉到 7 人。212 手头只有 1.74609375 粮，现有商路贡献 3 粮。商路从实际出发路线表消失时，邢州从净粮 0 变为 −3。213 扣粮后库存读到 −1.25390625，人口降到 7，原版缺粮通知出现。此后商人才重开同一路线，面板回到净粮 +3。

| 213，玩家开始行动 | 无 | 7 | 14 / 0 | 35 |
| 213，同一商人重开路线 | 邢州 → 胶东 | 7 | 17 / +3 | 35 |

Gameplay 独立读到了 8 人时的 13 粮／净 −3，以及变成 7 人的事件。UI 提供路线和库存，两个环境的回调快照不是同一瞬间，不能用它们推断引擎内部指令的精确顺序。路线少 3 粮与原版贸易收益的三项计算相符；本次复测没有区分路线自然结束与其他移除原因，也没有验证能提前读取剩余回合。
