# 跨上下文时钟偏移：离线边界工具

[intersect_offsets](../../tools/clock_offsets.py)接收非空三元组序列：UI调用前时刻、核心读取时刻、UI返回后时刻。只有确知核心读取发生在这两个UI读取之间，并假设这批样本采用固定偏移时，才可将每条记录转为Core减UI的可能偏移区间，再求交集。输出samples、lower_seconds、upper_seconds和consistent四字段；无交集保留冲突上下界，不修补数据。

例如(10,5,12)允许偏移[-7,-5]；与(20,15,25)相交仍为[-7,-5]。Core时刻不必落在UI原数值范围内，偏移可以为负。禁止空输入、文本／映射形状、布尔、非有限／负值与无法表示的时间；UI终点早于起点时，先按原始数值拒绝，再转换浮点。
