# 211 实机：西安开工水坝，邢州再次缺粮

从 210 的完成态继续，普通结束回合先停在世界议会，未立即换回合。测试玩家用原版界面投了军事顾问（远程攻击）、贸易政策（白绮）及外交胜利（白绮）各 1 张免费票，确认费用 0。提交一次，结果页返回游戏后实际到 211。没有重发结束回合、强制结束或人工排产。

![世界议会由玩家投票：原版确认页显示费用为0](images/source113-dam-food211/world-congress-review210.png)

西安下水道完成后，托管在三个合法坝址中选了 2569（53,34）。日志记录一笔后台水坝请求和一次实际队列读回，原洪泛平原农场已进入水坝施工，队列进度 0/197，预计 4 回合。上海有合法坝址，但原规划器这一轮选了工业区（72 分，高于水坝 35 分）。只证明了实际开工，没有证明建成或防洪效果。观察器已撤回。

![西安211：原版生产面板显示堤坝在建](images/source113-dam-food211/xian-dam-started211.png)

邢州同回合重新缺粮。先前调给它的 2277 仍归邢州，旧救粮记录仍是 `OBSERVED`。但原社区完工后，托管把下一座社区放到这格；它从有 1 人工作、产 1 粮，变成施工地、产 0 粮。工业区回到 2 位专家，邢州总粮回到 15，净 −1，8 人、两回合后掉人口。原救粮策略重新读取到 5 个换地候选，没有安全可用方案。之前 208–210 和完成态读档的结果仍成立；这个新失败表明，长期保住粮食还需要让区域选址尊重现有工作粮格。

![邢州211：新社区施工后重新出现红色掉人口倒计时](images/source113-dam-food211/xingzhou-food-recurrent211.png)

已保存 211 失败现场、保留原 210 档，没有再结束回合。下一步补新区域的粮食损失校验，并在提交建造前重读实际工作与盈余；现有生产不取消，不加入手动地块入口。Steam 离线，工坊仍为内部 82。
