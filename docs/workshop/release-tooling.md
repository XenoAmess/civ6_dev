# Alpha发布工具：离线准备与更新现有条目

发布工具现在按`--release`选择独立版本目录与验证清单。默认仍为`v0.1.0-alpha.1`，保留其74／87文件历史基线；当前源码82不能冒用旧清单。新版本需要自己的`docs/workshop/<release>/package.json`和`docs/releases/<release>/verification.json`，构建号、文件数、完整路径与SHA256必须匹配当前产品。目录、软链接、重复文件和不同的既有暂存内容会被拒绝。

`prepare_workshop.py`只读校验或写入工作区`dist/workshop`下的新暂存目录，不初始化Steam。`publish_workshop.py`增加`inspect`和`update-content`；后者只更新显式指定、与版本计划一致的已有工坊条目，包含产品、正文和主封面，不新建条目、不改变可见性。图库通过`append-preview`一次补一张，保留旧图；数量与文件名按版本核对，不再固定7张。

运行发布器前必须取得新鲜可靠的其他设备游戏占用状态，再显式提供`--remote-idle-confirmed`。该参数只是操作员声明，不是自动无人证明；不得从好友离线、API失败或本机验收进程推断账号空闲。详见[Steam流程](../steam-offline-workflow.md)。本包没有取得新的占用清闲确认，也没有联网、初始化Steam API或上传。

每次更新保留独占意图与结果日志，未知返回不能自动重发。Alpha1继续使用原日志目录，新版本隔离日志，避免隐藏旧意图。协议需要用户处理时停止。上传成功后的SDK读回仍不是下载文件一致证明；须再下载核对产品清单，并恢复Steam离线。

14项离线测试方法通过，含一个使用本机官方SDK程序集的C#5编译与20项纯本地助手检查。反射只调用文件、图库和日志助手，不调用发布器Main或Steam API。测试覆盖版本错配、布尔冒充整数、清单篡改／重复／路径逃逸、软链接、暂存覆盖拒绝、缺占用确认提前阻断、旧7图与新10图的增补及日志重放拒绝。它们不授联网SDK、工坊发布或游戏效果通过。
